# Bookstore Marginalia

> **[Generate this style in PixPix →](https://www.pixpix.com/?source=github13)**

[中文](README.md)

An original `居家日常` image-making Skill. It keeps the upper part of a photograph recognisable, then rebuilds the lower panel as a blank margin field, abstract page edges and small shelf-object drawings. The goal is bookstore imagery without copying covers or pages.

## Best for

book stack, hands, shelf texture and tote. Its default tone is thoughtful and urban, with paper white, ink, burgundy and the tactile character of newsprint, pencil, stamped texture.

## Use

`Use $photo-to-bookstore-marginalia to process this photo at editorial density, focusing on one detail that matters to me.`

## Install in Codex

1. Clone or download this repository: `git clone https://github.com/Jack-chen-cyber/awesome-memory-image-skills.git`.
2. Copy the complete `skills/photo-to-bookstore-marginalia` directory into Codex's Skills directory; on Windows, the default is `%USERPROFILE%\.codex\skills\photo-to-bookstore-marginalia`.
3. Restart or reload Codex, then invoke `$photo-to-bookstore-marginalia` in a conversation.

Do not copy only `SKILL.md`; keep `agents/`, `LICENSE.md`, and the page files with the Skill.
