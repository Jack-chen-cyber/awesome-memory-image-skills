# Bookstore Marginalia / 书店页边笔记

> **[在 PixPix 生成这个风格 →](https://www.pixpix.com/?source=github13)**

[English](README_EN.md)

这是「居家日常」系列的原创图片创作 Skill。上传一张照片后，上半保留可辨识的真实瞬间；下半以 **a blank margin field, abstract page edges and small shelf-object drawings** 重新创作，重点是 bookstore imagery without copying covers or pages。

## 适合的照片

book stack, hands, shelf texture and tote。默认气质为「thoughtful and urban」，使用 paper white, ink, burgundy 的克制配色，并保留 newsprint, pencil, stamped texture 的触感。

## 使用方式

`用 $photo-to-bookstore-marginalia 处理这张照片，选择 editorial 密度，并把重点放在我最在意的一个细节上。`

## 安装到 Codex

1. 克隆或下载本仓库：`git clone https://github.com/Jack-chen-cyber/awesome-memory-image-skills.git`。
2. 将完整目录 `skills/photo-to-bookstore-marginalia` 复制到 Codex 的 Skills 目录；Windows 默认可用 `%USERPROFILE%\.codex\skills\photo-to-bookstore-marginalia`。
3. 重启或重新加载 Codex，然后在对话中调用 `$photo-to-bookstore-marginalia`。

不要只复制 `SKILL.md`：请保留同目录中的 `agents/`、`LICENSE.md` 和页面文件。
