1. 克隆或下载本仓库：`git clone https://github.com/Jack-chen-cyber/awesome-memory-image-skills.git`。
2. 将完整目录 `skills/photo-to-flower-market-ephemera` 复制到 Codex 的 Skills 目录；Windows 默认可用 `%USERPROFILE%\.codex\skills\photo-to-flower-market-ephemera`。
3. 重启或重新加载 Codex，然后在对话中调用 `$photo-to-flower-market-ephemera`。
