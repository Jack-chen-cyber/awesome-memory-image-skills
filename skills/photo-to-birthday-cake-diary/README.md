# Birthday Cake Diary / 生日蛋糕日记

> **[在 PixPix 生成这个风格 →](https://www.pixpix.com/?source=github12)**

[English](README_EN.md)

这是「关系纪念」系列的原创图片创作 Skill。上传一张照片后，上半保留可辨识的真实瞬间；下半以 **a painted cake detail, wrapper texture, ribbon and abstract sparkle forms** 重新创作，重点是 a celebration post that is instantly understandable。

## 适合的照片

cake shape, candlelight, flowers and table colour。默认气质为「sweet but grown-up」，使用 buttercream, berry, candle gold 的克制配色，并保留 gouache, crinkled paper, wax 的触感。

## 使用方式

`用 $photo-to-birthday-cake-diary 处理这张照片，选择 editorial 密度，并把重点放在我最在意的一个细节上。`

## 安装到 Codex

1. 克隆或下载本仓库：`git clone https://github.com/Jack-chen-cyber/awesome-memory-image-skills.git`。
2. 将完整目录 `skills/photo-to-birthday-cake-diary` 复制到 Codex 的 Skills 目录；Windows 默认可用 `%USERPROFILE%\.codex\skills\photo-to-birthday-cake-diary`。
3. 重启或重新加载 Codex，然后在对话中调用 `$photo-to-birthday-cake-diary`。
