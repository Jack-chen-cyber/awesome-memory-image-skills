# Cobalt Travel Tile / 钴蓝旅行瓷片

> **[在 PixPix 生成这个风格 →](https://www.pixpix.com/?source=github10)**

[English](README_EN.md)

这是「纸感旅行」系列的原创图片创作 Skill。上传一张照片后，上半保留可辨识的真实瞬间；下半以 **a grid of hand-painted cobalt tile fragments and one soft map contour** 重新创作，重点是 a souvenir that feels collected rather than purchased。

## 适合的照片

coastline, tiled facade, luggage detail and afternoon light。默认气质为「sunlit and composed」，使用 chalk white, cobalt, faded sand 的克制配色，并保留 unglazed ceramic, cotton paper, pencil line 的触感。

## 使用方式

`用 $photo-to-cobalt-travel-tile 处理这张照片，选择 editorial 密度，并把重点放在我最在意的一个细节上。`
