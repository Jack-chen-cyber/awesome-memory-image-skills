这是「玩趣收藏」系列的原创图片创作 Skill。上传一张照片后，上半保留可辨识的真实瞬间；下半以 **one stylised outfit outline, accessory doodles and three pattern chips** 重新创作，重点是 personal style rendered as a casual fashion sketch。

## 适合的照片

outfit, pose, pattern and accessory。默认气质为「spontaneous and chic」，使用 outfit-sampled colours plus white 的克制配色，并保留 marker, pencil, textured notebook 的触感。

## 使用方式

`用 $photo-to-fashion-doodle-diary 处理这张照片，选择 editorial 密度，并把重点放在我最在意的一个细节上。`

## 安装到 Codex

1. 克隆或下载本仓库：`git clone https://github.com/Jack-chen-cyber/awesome-memory-image-skills.git`。
2. 将完整目录 `skills/photo-to-fashion-doodle-diary` 复制到 Codex 的 Skills 目录；Windows 默认可用 `%USERPROFILE%\.codex\skills\photo-to-fashion-doodle-diary`。
3. 重启或重新加载 Codex，然后在对话中调用 `$photo-to-fashion-doodle-diary`。

不要只复制 `SKILL.md`：请保留同目录中的 `agents/`、`LICENSE.md` 和页面文件。
