# Candlelight Dinner Card / 烛光晚餐卡

> **[在 PixPix 生成这个风格 →](https://www.pixpix.com/?source=github15)**

[English](README_EN.md)

这是「居家日常」系列的原创图片创作 Skill。上传一张照片后，上半保留可辨识的真实瞬间；下半以 **a minimal table-setting study, folded menu-like blank card and metallic light mark** 重新创作，重点是 dinner imagery reframed as a tiny art object。

## 适合的照片

plates, candle, glass, flower and table shadow。默认气质为「intimate and elevated」，使用 wine, cream, brass 的克制配色，并保留 vellum, candle wax, soft grain 的触感。

## 使用方式

`用 $photo-to-candlelight-dinner-card 处理这张照片，选择 editorial 密度，并把重点放在我最在意的一个细节上。`

## 安装到 Codex

1. 克隆或下载本仓库：`git clone https://github.com/Jack-chen-cyber/awesome-memory-image-skills.git`。
2. 将完整目录 `skills/photo-to-candlelight-dinner-card` 复制到 Codex 的 Skills 目录；Windows 默认可用 `%USERPROFILE%\.codex\skills\photo-to-candlelight-dinner-card`。
3. 重启或重新加载 Codex，然后在对话中调用 `$photo-to-candlelight-dinner-card`。

不要只复制 `SKILL.md`：请保留同目录中的 `agents/`、`LICENSE.md` 和页面文件。
